# Cadre

Cadre is a desktop workspace for coding agents. It coordinates research,
planning, implementation and code review using Claude Code, Codex or Cursor.

This repository contains public release notes and desktop downloads. The
application and engine source repositories are maintained separately.

## Downloads

Desktop installers will appear on the [Releases page](https://github.com/ayorcodes/cadre/releases)
as they become available. The Mac build is for Apple silicon.

Each desktop release includes a `SHA256SUMS.txt` file for checking the installer.
